# Voces de referencia

Cada voz debe tener dos archivos con el mismo nombre:

```text
voices/
  Ana.wav
  Ana.txt
```

`Ana.txt` debe ser la transcripción literal de `Ana.wav`, codificada como UTF-8. Usa una muestra limpia, de una sola persona y sin música ni silencios largos. La aplicación detecta automáticamente las voces al iniciarse o al pulsar **Actualizar voces**.
